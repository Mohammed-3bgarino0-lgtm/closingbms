# BestShield | تطبيق التقفيل المالي

تطبيق ويب عربي لتسجيل إيصالات فروع **القادسية** و**السويدي**، ومراجعة التقفيل اليومي، ثم تصدير تقرير مفصل للإدارة المالية بصيغة Excel. يعمل من المتصفح دون Excel ودون تثبيت حزم برمجية.

## كيف يستخدمه الموظف؟

1. يختار الفرع وتاريخ العمل.
2. يكتب قيمة الإيصال ويختار وسيلة الدفع (كاش، مدى، فيزا، ماستركارد، تابي، تمارا، تحويل بنكي).
3. يدخل رقم فاتورة BMS ومرجع الإيصال للتتبع، ثم يضغط **إضافة الإيصال**.
4. يكرر الإجراء لكل إيصال. تظهر الإيصالات في سجل اليوم مع مجاميع كل وسيلة دفع.
5. في صفحة «التقفيل والمالية» يسجل أرصدة BMS ويجرد الصندوق.
6. يضغط **تصدير للمالية Excel** ثم يرسل ملف التقرير إلى الإدارة المالية بالطريقة المتبعة في الشركة.

## تشغيل محلي

افتح `index.html` في متصفح حديث. بعض إعدادات المتصفح قد تحد من حفظ البيانات في الملفات المحلية؛ الأفضل استخدام خادم ويب أو نشر التطبيق على GitHub Pages.

## النشر في GitHub Pages

1. أنشئ مستودعًا جديدًا في GitHub، مثل `bestshield-closing`.
2. فك ضغط ملف `BestShield_GitHub_Ready.zip` **قبل** رفعه: GitHub لا يستخرج محتوى ZIP عند رفعه كملف واحد.
3. اختر **Add file → Upload files**، ثم ارفع الملفات والمجلد `.github` إلى **جذر المستودع** (تأكد أن `index.html` في الجذر).
4. احفظ الملفات في فرع `main`.
5. افتح **Settings → Pages → Build and deployment → Source → GitHub Actions**.
6. من تبويب **Actions** تابع تشغيل `Deploy BestShield app to GitHub Pages`؛ بعد نجاحه ستظهر صفحة التطبيق على عنوان GitHub Pages الخاص بالمستودع.

> **تنبيه مهم:** GitHub Pages استضافة لموقع ثابت وليس قاعدة بيانات مشتركة. التطبيق لا يزامن إيصالات القادسية والسويدي بين الأجهزة، ولا يقدم تسجيل دخول أو اعتمادًا مركزيًا أو إرسالًا آليًا إلى المحاسب. البيانات محفوظة محليًا في متصفح كل جهاز، وقد تضيع عند مسح بيانات الموقع، لذا يجب تنزيل النسخ الاحتياطية وتصدير التقارير بانتظام. النشر في مستودع عام يجعل واجهة التطبيق متاحة للجمهور، فلا تعتبر هذا الإصدار نظامًا ماليًا آمنًا متعدد المستخدمين أو تنشر معه أي مستندات مالية فعلية.

## هيكل المستودع

```text
index.html                 تطبيق التقفيل الكامل
.nojekyll                  إعداد GitHub Pages
.github/workflows/pages.yml نشر تلقائي بعد رفع التعديلات
.gitignore                 منع رفع تقارير مالية وبيانات حساسة بالخطأ
README.md                  تعليمات التشغيل والاستخدام
SECURITY.md                حدود الأمان وحفظ البيانات
```

## ملاحظات

- كل إيصال يسجل كعملية مستقلة، مع إمكان تسجيل الاسترجاع وحفظ أثر إلغاء الإدخالات.
- يحفظ التطبيق البيانات في `localStorage` داخل المتصفح، **ولا** يرسلها إلى خدمة خارجية.
- تصدير Excel وإنشاء مسودة بريد للمالية لا يعني إرسال الملف تلقائيًا.
- إذا احتجت حفظًا مركزيًا وصلاحيات للموظفين والمحاسبين، يلزم إضافة خادم/قاعدة بيانات ونظام دخول وتدقيق.
